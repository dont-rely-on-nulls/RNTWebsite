#+WINDOW: Applications
#+WEIGHT: 3

On NT, Notepad is a Win32 program and =ls= was a POSIX one: applications sit
above the subsystems and borrow their personalities. RNT has the same top
layer, with one difference. An NT program belongs to one subsystem; an RNT
application can use several at once, because they all meet in the same
object tree.

An application has no language of its own. It is a package of relations,
routines and constraints under =\application=, installed by merging a branch
and removed by reverting it. Four games and a package manager show the
idea: in each one the state is relations, a change is a commit, and taking
it back is checking out the commit before.
