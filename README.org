#+TITLE: RNT website

The website for [[../RNT][RNT]], /Relations, Not Tables/, and its environment
subsystems: Sakura, pureSQL, Forth, Karuta, Sol, Dandelion and Aleph. It is a [[https://gohugo.io][Hugo]] site whose
content is written in org mode; Hugo renders =.org= files itself, so no
Emacs export step is involved.

* Layout
| Path                   | Holds                                                    |
|------------------------+----------------------------------------------------------|
| =content/_index.org=     | the hero: eyebrow, headline, introduction                |
| =content/home/=          | the home page windows, in order of =#+WEIGHT=            |
| =content/subsystems/=    | one page per subsystem                                   |
| =data/architecture.toml= | the NT-style layer diagram                               |
| =data/objecttree.toml=   | the object tree listing                                  |
| =layouts/=               | templates: the desktop, its windows and the menu bar     |
| =static/images/=         | the isometric solids and the wallpaper tile              |

The files under =content/home/= are read by the home page and are never
rendered as pages of their own.

** A subsystem page
Front matter names its icon, the accent of its tagline, its port and the
facts shown in its window. Whatever comes before =# more= is what the home
page shows; the rest appears only on the subsystem's own page.

#+begin_src org
,#+TITLE: Forth
,#+WEIGHT: 3
,#+TAGLINE: A machine made of relations
,#+SHORT: Forth 2012 on a relational machine
,#+PORT: 7779
,#+ICON: forth-bricks.svg
,#+ACCENT: forth
,#+FACTS: Atomic lines · UNDO · CATCH / THROW · TCP :7779

The summary shown on the home page.

,# more

,* The machine
Shown only on the subsystem's page.
#+end_src

A title split with =|= breaks into lines: =Relations, | not tables.=

* Working on it
#+begin_src sh
nix develop            # a shell with Hugo
hugo server            # http://localhost:1313
#+end_src

* Deploying
Pushing to =main= runs =.github/workflows/pages.yml=, which builds the site
and publishes it with GitHub Pages. In the repository's settings, under
/Pages/, set the source to /GitHub Actions/. The workflow sets the base URL,
so the site works both at a project path and on a custom domain.

The source, docs and license links are =sourceURL=, =docsURL= and
=licenseURL= in =hugo.toml=.
